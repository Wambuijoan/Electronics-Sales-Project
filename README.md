# Electronics Sales Power BI Dashboard

An interactive Power BI dashboard analyzing electronics sales performance across the **USA and Canada**, built to surface revenue trends, product performance, and regional sales patterns for business decision-making.

## Overview
This project turns raw electronics sales transaction data into a decision-ready dashboard. 

## Tools & Tech
- **Power BI** - data modeling, DAX measures, dashboard/report design
- **Power Query** - data cleaning and transformation

## What I did
- Cleaned and shaped raw sales data for analysis (removed duplicates, standardized categories, handled missing values)
- Built a data model connecting sales, product, and regional dimensions
- Wrote DAX measures for KPIs (e.g. total revenue, profit margins, average order value)
- Designed an interactive report with filters/slicers for region, product category, and time period

## Key Insights
- High-revenue products don't have the best margins. MacBook Pro and TVs bring in the most sales (around 15K each), but their profit margins are actually the lowest (7.5%–14%). Smaller accessory items like the Sonos speakers sell less overall but hit margins up to 20%, which could be worth exploring for bundling or upselling.
- Tuesday is by far the busiest sales day, pulling in about 40K, more than double any other day. The shop is closed on Mondays.
- Customers are almost evenly split between the US and Canada (50.87% vs 49.13%), spread across 8+ cities including Boston, Toronto, Miami, and Montreal.
